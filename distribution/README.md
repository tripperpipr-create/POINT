# Дистрибутив Point IDE

Point — **самостоятельная** лёгкая Windows IDE на базе Code-OSS. Это не перекрашенный VS Code и не оболочка вокруг установленного Code: редактор, консоль, Git, отладчик, каталог реликвий (Open VSX), русский интерфейс и локальная Гильдия агентов поставляются одним приложением. Движок остаётся Code-OSS (MIT); продуктовая поверхность — Point.

Актуально для Point `1.2.2` на 26 августа 2026 года. Версия Code-OSS, commit,
Node и SHA-256 language pack не дублируются из памяти: канонический manifest —
`distribution/version.json`.

## Что входит в сборку

- Code-OSS `1.124.2` (`win32-x64`) из официального репозитория Microsoft, закреплённый по commit SHA в `version.json`.
- Собственный бренд Point, предоставленная пользователем иконка, URI-схема и отдельные каталоги пользовательских данных.
- Point Dark, собственная главная, русский онбординг и переключение недавних проектов по `Ctrl+Alt+P`.
- Встроенное системное расширение `local-agent-workbench` с Гильдией персонажей-агентов, квестами и локальной Хроникой.
- Agent Hub `1.2.2`: компаньон встроен в IDE (статус-бар, `Ctrl+Alt+;`, Quick Fix, тост на сбой задачи, полоска на Квестах/Флоу/Отрядах). Blueprint и проектные агенты, навыки, команды, квесты, Flow, память, подключения, статистика и безопасное ревью Change Set. Приложение запускается без аккаунта; upstream Microsoft sessions onboarding и Copilot Agent Host отключены.
- Пятишаговая Студия компаньона: режим, безопасное подключение и реальный probe моделей, характер с живым предпросмотром, неизменяемые границы действий и интерактивные примеры с тестовым ответом. Ключи остаются только в SecretStorage IDE.
- Типизированные вложения контекста: локальное извлечение PDF, DOCX, XLSX, CSV/TSV и JSON, мультимодальные изображения, SHA-256 снимки и оценка размера/токенов до запуска.
- Визуальный конструктор пользовательских инструментов: безопасный direct-process без неявного shell, типизированные параметры и пути, argv-пресеты, импорт/экспорт JSON, неисполняющая песочница тестовых значений и точный preview перед обязательным одноразовым подтверждением; фиксированные shell-команды сохранены для совместимости.
- Неизменяемый снимок конфигурации каждого запуска: промпт, модель, лимиты и определения выбранных инструментов остаются в истории после дальнейших правок профиля.
- Fingerprinted preflight до обращения к модели: точный system prompt, schemas/approval инструментов, вложения, оценка токенов и защита от запуска устаревшей конфигурации.
- Локальная диагностика запусков без дополнительного обращения к модели: токены, задержки, tool errors, ожидание подтверждений, патчи, причина остановки и проверка изменений; два последних запуска сравниваются в истории.
- Визуальный конструктор последовательных workflow на 1–12 агентов с настройкой контекста, безопасной передачей результата, временной шкалой и общей отменой.
- Встроенное локальное ядро `point-core.exe`: REST/SSE API, безопасные workspace-инструменты, подтверждение команд и патчей.
- SQLite для истории и состояния, локальный TTL-кеш для desktop-режима.
- Русский language pack `MS-CEINTL.vscode-language-pack-ru`, проверяемый по SHA-256.
- Open VSX как **каталог реликвий Point**. Microsoft Marketplace намеренно не используется.
- Универсальная навигация по коду: Point объединяет файлы, классы, интерфейсы, функции и переменные в поиске `Ctrl+N`, открывает стабильное дерево использований по `Alt+F7` и использует language providers без привязки к конкретному ЯП.
- 74 встроенных описания языков для подсветки и базовой структуры. Полноценные language servers для Go, Python, Java, Rust, C/C++, C#, PHP, Ruby, Kotlin, Scala, Dart/Flutter, Vue, Svelte, Astro, YAML, Shell и SQL подключаются из языкового центра только по требованию.
- «Инвентарь» показывает дерево файлов, а «Летопись» — изменения, репозитории и локальный Git без обязательного аккаунта.
- Увеличенный по умолчанию масштаб интерфейса (`window.zoomLevel = 0.5`).
- Стабильный программный compositor включён по умолчанию: на проверенной Windows-сборке он сократил private memory примерно на 120 МиБ и убрал длинные задержки первых кадров. Для явного возврата аппаратного GPU запустите Point с переменной окружения `POINT_ENABLE_HARDWARE_ACCELERATION=1` (ожидайте +~120 МиБ private memory и возможные микростаттеры на слабых GPU).
- Crash reporter не запускается. В простое разрешён один extension host для фоновых наблюдений помощника, но локальное ядро `point-core` и индекс не поднимаются до реального обращения к их функциям. Каталоги зависимостей и сборочных результатов исключены из watcher/search/индекса Point по умолчанию.
- Обновления квеста сериализованы, имеют 20-секундный HTTP-тайм-аут и не перерисовывают скрытые или неизменившиеся RPG-панели.

## Готовые артефакты

- Установщик: `build/code-oss/PointSetup-x64-1.124.2.exe`.
- Portable-приложение: `.cache/VSCode-win32-x64/Point.exe`.
- Манифест версии и SHA-256: `build/code-oss/release.json`.
- CycloneDX 1.7 SBOM установщика: `build/code-oss/point-installer-sbom.cdx.json`.

`publish-release.ps1` генерирует SBOM из фактически упакованных app/extension
manifest, транзитивных `node_modules` и ключевых файлов, затем проверяет его до
записи хеша и component count в `release.json`.

Установщик сейчас не подписан сертификатом издателя, поэтому Windows SmartScreen может показать предупреждение. Для публичного релиза нужен code-signing certificate и шаг подписи в CI.

## Воспроизводимая сборка

Требования: Windows 10/11 x64, Git, Python 3, Visual Studio 2022 с workload **Desktop development with C++** и Windows SDK 10.0.26100 или совместимый.

Из корня репозитория запустите:

```powershell
.\distribution\install-build-runtime.ps1
.\distribution\sync-code-oss.ps1
.\distribution\build-code-oss.ps1
```

Если `python.exe` отсутствует в `PATH`:

```powershell
.\distribution\build-code-oss.ps1 -PythonPath 'C:\Python313\python.exe'
```

Повторно упаковать уже собранное приложение после изменения встроенного расширения:

```powershell
.\distribution\build-code-oss.ps1 -SkipInstall -InstallerOnly -PythonPath 'C:\path\to\python.exe'
```

Скрипт каждый раз проверяет закреплённые версии, собирает `point-core.exe` и
`point-db.exe`, накладывает overlay, собирает нативные Electron-модули, формирует
portable-каталог и Inno Setup installer, затем записывает контрольную сумму
релиза. `point-db.exe` выполняет проверяемые backup/migrate-copy/offline restore;
операционный порядок описан в [operations.md](../docs/operations.md).

Overlay отключает Copilot-зависимые onboarding и Agent Host, оставляя Point полностью локальным и не требующим аккаунта. Совместимый `defaultChatAgent`-контракт сохраняется только для внутренних API новой версии Code-OSS, но все upstream login-flow пропускаются. Renderer smoke проверяет Chromium-консоль, логи workbench, отсутствие окон входа и фонового Copilot-провайдера; живой Electron-процесс с пустым окном или запросом авторизации не считается успешным запуском.

## Устройство desktop-версии

```text
Point / Electron
  └─ встроенное расширение Point
       ├─ главная, проекты, нативная панель агента и онбординг
       ├─ Workspace Trust
       └─ loopback REST/SSE
            └─ point-core.exe (Go)
                 ├─ агент и провайдеры моделей
                 ├─ policy/approval layer
                 ├─ безопасные workspace tools
                 ├─ SQLite audit store
                 └─ memory TTL cache
```

Сервис слушает случайный loopback-порт и запускается только для доверенной локальной папки. Команды и изменения файлов требуют подтверждения согласно выбранному профилю безопасности. Docker, Redis и внешний веб-сервер для desktop-режима не нужны; они остаются отдельным вариантом развёртывания веб-интерфейса.

## Отличия от фирменного Visual Studio Code

Репозиторий `microsoft/vscode` доступен по MIT License, но готовая сборка Microsoft включает отдельный брендинг и product-specific configuration. Поэтому дистрибутив основан именно на Code-OSS, имеет собственные идентификаторы Point (`.point`, URI `point://`, меню/About/Главная) и использует Open VSX как каталог реликвий. Help-ссылки ведут на `point.invalid`, а не на microsoft.com/vscode. Автообновление пока отключено: новые версии выпускаются новым установщиком.

Что уже отделено на уровне продукта: имена, dataFolder, Copilot/chat chrome, аккаунты, нативная Главная, Инвентарь/Летопись/Агенты/Реликвии, JetBrains-навигация. Что по-прежнему наследуется от Code-OSS: Monaco, workbench layout engine, протокол расширений VS Code API, встроенные language grammars и upstream command IDs в палитре (часть команд ядра всё ещё с английскими upstream-именами до полного gulp с nls).

Для текущей локальной среды сборка нативных модулей использует флаг компилятора `/Qspectre`, а при отсутствии Spectre-mitigated CRT libraries связывается со стандартным VC runtime. Для официального production-релиза рекомендуется установить Spectre libraries через Visual Studio Installer и подписывать итоговые EXE.
