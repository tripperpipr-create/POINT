# Point RPG UI

Point использует игровую метафору как рабочую информационную архитектуру, а не как декоративную тему.

Актуально для Point `1.2.2` на 2 сентября 2026 года. Канонические значения
находятся в `ui/tokens.css` и `ui/budget.json`; числа ниже описывают текущие
файлы, если явно не помечены как исторический замер.

## Словарь

| Рабочая сущность | Название в Point | Назначение |
| --- | --- | --- |
| Project / workspace | Мир | Изолированный контекст проекта |
| Explorer | Инвентарь | Файлы и артефакты мира |
| Git / Source Control | Летопись | Проверяемая история изменений |
| Agent profile | Агент | Роль, модель, права, лимиты и инструменты |
| Task / run | Квест | Конкретная цель и её фактический прогресс |
| Workflow | Отрядный квест | Последовательная работа нескольких персонажей |
| Tool | Инструмент | Разрешённая возможность агента |
| Context attachment | Артефакт | Файл, выделение или документ в контексте квеста |
| Events / logs | Журнал | Неизменяемые события локального ядра |
| Diagnostics | Свиток состояния | Время, токены, сбои и подтверждения |
| Editor tabs | Книга квестов | Открытые пути и артефакты текущей работы |
| Breadcrumbs | Путь героя | Точное положение файла в мире проекта |
| Terminal | Консольный канал | Настоящая интерактивная оболочка во вкладке редактора |
| Command palette | Меню действий | Быстрый вызов команд Point и редактора |

С 24 сентября 2026 года в Агент-Хабе держится **ядро метафоры**: остаются
Квест, Гильдия, Отряд, Уровень и Опыт. Синонимы, которые говорили об одном и том
же разными словами, сведены к одному: персонаж и специалист — агент; умение и
арсенал — инструмент; хроника — история (у ядра — журнал ядра); летопись правок —
журнал правок; разведка — предпросмотр; найм — новый агент. Подписи набираются
обычным регистром: прописные с разрядкой были голосом прежнего «Чертога».

Игровые показатели не выдумываются: уровень зависит от завершённых квестов, надёжность — от доли успешных финалов, умения — от реального allowlist профиля, прогресс — от зафиксированных ходов и лимита.

## Два регистра

Point использует два визуальных регистра, которые не смешиваются.

| | Оболочка | Агент-Хаб |
| --- | --- | --- |
| Где | Боковая панель, компаньон, встроенные панели | Окно Хаба: разговор с Мастером, настройки проекта, статистика, Docker |
| Референс | JetBrains: тихо, плотно, функционально | Тот же тихий регистр; RPG — словами, уровнем, опытом и характеристиками агента |
| Источник цвета | Мост к теме VS Code, фолбэк — графит Point Dark | Тот же мост `--ui-*`, через ступени `--hub-*` |
| Базовый кегль | 13 px | 13 px |

Регистр выбирается атрибутом `data-layout` на `body`. Слои пишут семантические имена
(`--surface-…`, `--text-…`), поэтому один компонент выглядит уместно в обоих регистрах.

Окно Хаба целиком следует теме IDE. Сначала так был устроен только разговор с
Мастером (`.is-chat`); 24 сентября 2026 года регистр распространён на всё окно —
настройки проекта, статистику и Docker: переход «чат → настройки» больше не
читается как переход в другое приложение, а светлая тема IDE больше не оставляет
Хаб чёрным. Блок `body[data-layout="wide"]` (и окна статистики и Docker) в
`tokens.css` переназначает ступени `--hub-*` на мост `--ui-*`, а цвета действия,
ссылки, фокуса и состояний берёт из `--ui-accent`, `--ui-link`, `--ui-focus`,
`--ui-success`, `--ui-error`, `--ui-warning`. Эти токены снимаются на `:root` до
того, как окно Хаба подменит переменные темы (`99-hall-canon.css`). Лента
оформляется слоем `07c-master-feed.css`, правая панель — `07d-master-inspector.css`;
значки — встроенные SVG из `ui/client/ui-icons.js`, цветом текста.

## Токены

Единственный источник истины — [`vscode-extension/ui/tokens.css`](../vscode-extension/ui/tokens.css).
`media/rpg-tokens.css` и `media/style.css` являются артефактами сборки и правке не подлежат.

### Поверхности

| Токен | Оболочка | Агент-Хаб «Чертог» | Роль |
| --- | --- | --- | --- |
| `--surface-void` | `#0A0A0A` | `#08080A` | Самый глубокий фон |
| `--surface-panel` | `#0E0E0E` | `#0B0B0D` | Рейка, шапка, панели |
| `--surface-raised` | `#151515` | `#0E0E10` | Карточки |
| `--surface-selected` | `#1C1C1C` | `#131315` | Выбранные элементы |
| `--surface-border` | `#222222` | `rgba(255,255,255,.08)` | Границы 1 px |
| `--text-primary` | `#e9e9e9` | `#E7E4DD` | Основной текст |
| `--text-muted` | `#989898` | `#A5A29B` | Вторичный текст |
| `--text-faint` | `--ui-muted` 90% | `#8A8780` | Третичный текст |

Столбец оболочки — фолбэки `--ui-*` из `tokens.css`, и он однажды уже отстал: в
таблице год стояли `#0A0A0A / #121212 / #1A1A1A / #242424 / #2E2E2E`, а в
`tokens.css` — нынешние значения. Из таблицы устаревшая палитра переехала
фолбэками в `point-native-home.css` и `point-workspace-trust.css` (57 мест) и
ждала там случая, когда токен не доедет. Расхождение теперь стережёт
`scripts/check-shell-scales.mjs`.

Границы Хаба заданы прозрачным белым, а не отдельным цветом: поверхность просвечивает,
и слои читаются как физические. Текстовая лесенка Хаба длиннее обычной — десять ступеней
от `--hub-text` до `--hub-faint-4`, потому что интерфейс плотный и иерархия держится
тоном, а не размером.

Столбец «Чертога» — палитра `:root`: фолбэк для регистра оболочки и мера для
`ui/contrast.mjs`. В окне Хаба она не действует. Акцент там — цвет кнопки темы, а
`--r-1…--r-3` — 4 / 8 / 8 px, геометрия редактора, а не чертежа. Всё, что писало
`var(--ember)` или `var(--r-2)`, переезжает вместе с регистром без правки разметки.

В оболочке значения приезжают из активной темы VS Code; приведённые цвета — это фолбэк
Point Dark. Поэтому чужая тема продолжает работать, а Хаб остаётся брендовой поверхностью.

### Акценты

Общие для обоих регистров. Акцент сообщает семантику, а не украшает поверхность.

| Токен | Цвет | Роль |
| --- | --- | --- |
| `--ember` | `#FF8A4C` | Главное действие и активный квест |
| `--arcane` | `#9676FF` | Агенты и их особенности |
| `--mana` | `#46D8E8` | Контекст, навигация и информация |
| `--vital` | `#5BCB8A` | Успех и надёжность |
| `--wound` | `#EE6873` | Ошибка и опасное действие |
| `--caution` | `#E0A24A` | Предупреждение, требует внимания |

К каждому есть заливка `--<имя>-wash` для фонов — вместо ручного `rgba`.

В регистре Хаба `--arcane` и `--mana` переопределены на нейтральные ступени: там они
не несли состояния, а раскрашивали тип элемента — подписи полей, ссылки, чипы
провайдера. Значащими в Хабе остаются `--vital`, `--wound`, `--caution` и единственный
залитый `--ember`. В оболочке обе роли работают как прежде. Исключение — разговор:
там ссылка темы (`--mana`) означает «идёт сейчас» у живого следа исполнителя.

Коралл «Чертога» означал сразу «главное действие» и «тревогу». В регистре темы
`--ember` — только главное действие (цвет кнопки темы). «Требует человека» — число
решений, непроверенный набор, агент без настройки — набирается `--caution`;
отказ и риск потери — `--wound`; добавленные и удалённые строки дифа — `--vital` и
`--wound`, как в редакторе.

Состояние квеста или прогона — точка и слово (`.status`), а не «печать» в рамке с
ромбом: идёт — ссылкой темы, ждёт человека — `--caution`, готово — `--vital`,
сорвалось — `--wound`, отменено — приглушённым текстом.

## Шкалы

Проект использует ratchet: сборщик считает значения вне шкал и роняет сборку,
если их стало больше (`ui/budget.json`). Текущий бюджет — 36 нарушений: 34 по
отступам и 2 обоснованных `!important` для reduced motion. Цель — уменьшать
остаток при переписывании конкретного слоя, не менять всю геометрию вслепую.

| Шкала | Ступени | Было до сведения |
| --- | --- | --- |
| Радиусы | `--r-1` 2px · `--r-2` 4px · `--r-3` 8px · `--r-full` | 14 значений от 2 до 15 px |
| Типографика | `--t-micro` 9 · `--t-tiny` 10 · `--t-small` 11 · `--t-body` 12 · `--t-base` 13 · `--t-lead` 15 · `--t-title` 18 · `--t-display` 22 | 24 значения, включая `7.5px`, `0.92em`, `9px !important` |
| Отступы | `--s-1` 2 · `--s-2` 4 · `--s-3` 6 · `--s-4` 8 · `--s-5` 12 · `--s-6` 16 · `--s-7` 24 · `--s-8` 32 | 135 уникальных значений |
| Тени | `--e-1` приподнятое · `--e-2` поповер · `--e-3` диалог · `--e-focus` | 35 вариантов |
| Высоты | `--control-sm` 24 · `--control-md` 28 · `--control-lg` 34 | произвольные |
| Акцентная кромка | `--edge-accent` 2px | 2px в двадцати местах и 3px в семи |

### Один регистр — одна геометрия

Регистр оболочки живёт в двух конвейерах: слои вебвью (`ui/layers/`, панели
инструментов) и листы поверх Code-OSS (`distribution/resources/point-*.css`,
хром окна). Шкалы для них одни и те же, но проверялись только слои — и оболочка
незаметно набрала свою систему: базовый радиус 4px вместо 2, кегли 10.5 · 11.5 ·
12.5, отступы 3 · 5 · 7 · 9 · 11 · 14 и два декоративных градиента в заголовке
окна. Отдельно от неё жила третья, «Nocturne» плотности 0.7 (`--nc-*`), на
которой были написаны панели инструментов. 4 сентября 2026 все три сведены в
одну: значения `--nc-*` стали синонимами ступеней канона, листы оболочки
переписаны на шкалы, счёт вне шкал доведён до нуля.

Стерегут это две проверки, обе в `npm run check`:

- `scripts/check-shell-scales.mjs` — кегли, радиусы, отступы, чужие цвета,
  декоративные градиенты и разошедшиеся фолбэки в `point-*.css`. Трещотка —
  `distribution/shell-budget.json`, там же названы отступления с причиной.
- `ui/type-scale.mjs` — теперь ещё и то, что `--nc-t-*` и `--nc-r*` объявлены
  через `var()`. Ступень, отмытую через токен, прежняя проверка считала чистой:
  `--nc-t-num: 10.5px` в `tokens.css` проходила мимо трещотки слоёв.

Значок — не текст. Метрика глифа (`--point-icon-sm` 14 · `-md` 16 · `-lg` 18)
живёт своей лесенкой и в типографическую шкалу не загоняется: иначе «сведение к
канону» означало бы уменьшение значков.

### Акцент редкий

В оболочке янтарь **не** красит наведение и выделение: под курсором может
оказаться что угодно, и смысла у этого нет. Подсветка — нейтральные ступени
подмесом текста (`--point-tint` · `-strong` · `-selected`), выбранное светлее
наведённого. Янтарь остаётся там, где он один на поверхность: кольцо фокуса,
линия активной вкладки, кромка закреплённой, точка изменённого файла, кнопка
запуска, метка проекта, полоса занятости, галочка текущего пункта, подсветка
найденного (`--point-match`).

## Геометрия и типографика

- Базовый ритм — 4 px.
- Границы — 1 px. Акцентная кромка слева — `--edge-accent`, 2 px: одна ширина
  для карточки, строки очереди, реплики и выдвижного ящика. Базовый радиус —
  2 px: это и есть «джетбрейновская» геометрия.
  8 px разрешён только всплывающим слоям — меню, диалогам, поповерам.
- Скруглённые «мобильные» карточки и декоративные градиенты не используются.
- Inter / Segoe UI Variable — интерфейс; JetBrains Mono / Consolas — код, статусы и метки.
- Нижняя граница кегля — 9 px, и только для прописных служебных меток (`.point-label`).
- Движение быстрое и незаметное: `--motion-fast` 90 мс, `--motion-base` 140 мс.
  При `prefers-reduced-motion` обе величины обнуляются — и потому длительность
  перехода пишется **только** токеном. Литерал `.14s` выглядит так же, но
  обнуления не видит: просьбу убрать движение он молча игнорирует. Так и жили
  одиннадцать деклараций с шестью разными длительностями до 2 сентября 2026.

## Исходники и сборка

```text
vscode-extension/ui/
  tokens.css      единственный источник истины: палитра обоих регистров и шкалы
  layers/*.css    33 слоя каскада, порядок задан именами
  client/*.js     редактируемые источники webview, сборка — build-js.mjs
  build.mjs       сборка CSS, структурная проверка и трещотка бюджета
  build-js.mjs    сборка media/main.js из client/*.js
  budget.json     зафиксированное число значений вне шкал
  contracts.mjs   сверка договорённостей ядра и интерфейса
  contrast.mjs    проверка контраста; plural.mjs и alphabet.mjs — русский текст
  preview.html    стенд: оба регистра, шкалы и проверка, что CSS распарсился
  hall.html, canon-probe.html   стенды Чертога и канонической геометрии
```

```powershell
cd vscode-extension
npm run build:css     # → media/style.css и media/rpg-tokens.css
```

`media/style.css` и `media/rpg-tokens.css` **генерируются**. Правки в них затираются
следующей сборкой — менять нужно `ui/tokens.css` или соответствующий слой.

Слои — это фактические исторические проходы по оформлению, а не выдуманное деление.
Имена честно называют, чем каждый был: `65-visual-pass`, `70-hub-layout-lock`,
`90-companion-quiet`, `95-companion-minimal`.

### Почему три слоя компаньона не схлопнуты

38 селекторов объявлены в двух или трёх слоях компаньона сразу. Соблазн слить их
в один файл велик, но слияние по свойствам меняет позицию правила в каскаде — а
вместе с ней и то, кто кого побеждает при равной специфичности. Правило,
переехавшее вперёд, начнёт проигрывать соседям; переехавшее назад — выигрывать у
тех, кому раньше уступало.

Проверить это на двух тысячах селекторов нечем: стенд покрывает полсотни. Поэтому
дубликаты остаются на месте до переписывания компаньона, когда у каждого правила
появится осознанный автор. Схлопывание ради красоты структуры не стоит тихой
поломки вёрстки.

### Навигация настроек проекта

Рейка — пять разделов (Обзор, Решения, Изменения, Квесты, Гильдия) и над ними
строка «← Чат с Мастером»: выход из настроек, а не ещё один раздел. Подраздел —
строка вкладок под шапкой (`hallSubtabsHtml` в `ui/client/quest-runtime-views.js`,
список — `HALL_SECTIONS`): у Гильдии это Агенты, Отряды, Навыки, Инструменты,
Память, Связи, Базы и Настройка. Раньше подразделы открывались только кнопками
«ПЕРЕЙТИ» внизу чужой страницы; эти подвалы сняты. Шапка — название раздела,
расход, метки очереди и «Статистика»; где вы внутри раздела, говорит выделенная
вкладка, поэтому надписи над заголовком страницы в разделах со вкладками нет.
Пока онбординг не закончен, рейка заперта, а строки вкладок нет.

### Один ритм страницы

Все разделы Чертога — Обзор, Решения, Изменения, Квесты, Агенты, История и
страницы Гильдии — используют одни поля `16 / 24 / 32`. Название раздела в шапке,
текст первой вкладки и содержимое стоят на одном левом краю. Раньше Ростер жил на 14 px, шапка на
16 px, а Хроника и Флоу были выключены по центру и на мониторе 1600 px начинались
на 314 px при крошке на 232 px. Проверяется замером — `scripts/audit-hub-layout.mjs`, 22 поверхности
на четырёх ширинах: расхождение левого края допускается только там, где
раскладка другая по замыслу — сплит «Решений», история по файлу и
центрированный диалог с Мастером.

Ширину содержимое не режет: панели Чертога — сетки `auto-fit`, они добирают
колонки на широком мониторе. Мера ограничена там, где расползается именно текст:
`56ch` у описаний раздела, `820px` у форм, `--hall-focus-max` у диалога.

### Окно, а не панель

Хаб живёт в отдельном окне, у которого своя рейка шириной до 208 px. Это ломает
предположения, собранные под панель редактора, и слой `99-hall-canon` чинит их
системно, а не по одному правилу:

- **Тема.** `tokens.css` объявляет, что Хаб не наследует тему VS Code, но
  исторические слои читали `--vscode-*` напрямую — одна только
  `--vscode-descriptionForeground` встречается 82 раза. Переменные темы
  переопределяются один раз на `body[data-layout="wide"]`, и каждое старое
  правило само приезжает в регистр окна — с 24 сентября 2026 года это тема IDE.
  Регистр оболочки этих определений не видит.
- **Акценты.** Бирюза и фиолетовый раскрашивали тип элемента, а не состояние:
  подписи полей, ссылки, чипы провайдера, карточки персонажей. Обе роли сведены
  к нейтральным ступеням лесенки Хаба. Значащие цвета остались значащими:
  `--vital`, `--wound`, `--caution` и единственный залитый акцент `--ember`.
- **Кнопки и формы.** Одна геометрия и один кегль на `.hall-btn`, `.primary`,
  `.secondary`, `.danger-button` и кнопки композера; залит ровно один шаг на
  экране. Форма — сетка в две колонки не шире 820 px: поле «Название» в 1160 px
  под подписью в 60 px было ошибкой вёрстки, а не плотностью.
- **Пороги.** Медиазапросы считают ширину окна, а колонкам достаётся ширина за
  вычетом рейки. Три колонки Ростера запрашивали 660 px там, где оставалось 624,
  и правая уезжала за край. Пороги подняты на ширину рейки, минимумы колонок
  сняты: сжатие лучше переполнения. С 24 сентября 2026 года колонок две: список
  агентов и лист выбранного — прогрессия стала первой строкой листа.

### Лист агента

Игровое в Гильдии — уровень, опыт и характеристики, и все они считаются по
сохранённым запускам. Карточка агента — имя, роль, плашка «Ур N», полосы опыта,
надёжности и доли инструментов и статус точкой. Эмблем в рамке со штриховкой нет:
один и тот же знак у каждого агента никого не отличал. Лист выбранного агента
начинается с уровня и опыта до следующего уровня, затем действия (одна залитая
кнопка — «Поставить задачу»), характеристики, роль, инструменты, профиль,
покрытие команды и история квестов.

### Отступы: почему шкала не навязана силой

Большая часть исторических литералов уже переведена в токены. В ratchet остаётся
34 нарушения категории `space`; их точный список вычисляет `ui/build.mjs`.
Сводить их к ближайшей ступени одной массовой заменой нельзя: изменение даже на
1–2 px способно поменять переносы, scroll-container и доступность кнопок.

Остаток уменьшается при переписывании конкретной поверхности. Перед и после
используются `ui/canon-probe.html`, render-board и layout audit. Исторические
baseline-числа сохранены в changelog и UI/UX-журнале, а не считаются текущими.

### Порядок вместо силы

Слой `98-canon-geometry` лежит в конце каскада намеренно. Раньше он стоял в середине
под именем `35-hub-rpg-canon` и навязывал свои значения семнадцатью `!important`,
потому что позже шли слои, спорившие с ним. Перенос в конец решает ту же задачу
порядком: правило выигрывает, но его по-прежнему можно переопределить обычной
специфичностью, а не ещё одним принудительным правилом.

Всего в слоях осталось **два** `!important`, оба — отключение анимаций внутри
`@media (prefers-reduced-motion: reduce)`. Это правильное применение: настройка
доступности обязана победить любое оформление.

Снятие проверялось замером, а не на глаз: `ui/canon-probe.html` содержит ровно те
элементы, которых касались принудительные правила, и сравнивает вычисленные стили
до и после. Все 50 селекторов дали ноль расхождений в обоих регистрах.

### Пространство имён «Чертога»

Классы слоя `05-hall.css` обязаны начинаться с `hall-` или `is-`. Это не стиль, а защита:
в исторических стратах есть правила с `!important` на общих именах вроде `.primary`, и
новый слой, переиспользовавший такое имя, проигрывает независимо от специфичности.
Сборка падает, если имя из «Чертога» занято другим слоём.

Сборщик отклоняет результат в трёх случаях:

1. **Структурная ошибка.** Например, `*/` внутри текста комментария закрывает его
   досрочно, и следующее правило молча исчезает. Баланс скобок такое не ловит.
2. **Рост числа значений вне шкал** относительно `budget.json`. Число может только
   уменьшаться; осознанное изменение фиксируется через `npm run build:css -- --record`.
3. **Коллизия имён** — класс «Чертога» без префикса, уже занятый другим слоём.

Стенд `ui/preview.html` открывается файлом в браузере и сам себя проверяет: считает
распарсенные правила и сверяет ключевые токены. Если правило потерялось, это видно сразу.

## Ограничения

- RPG-термины не скрывают техническое действие: в описании и подсказке всегда остаётся точный смысл.
- Опыт, надёжность, прогресс и награда строятся только из сохранённых фактов.
- Ошибки, разрешения и потенциально опасные команды визуально сильнее декоративных состояний.
- Редактор кода остаётся главным экраном; игровой слой не расходует память на анимации, 3D или фоновые процессы.
- Широкие RPG-экраны создаются лениво как вкладки редактора и уничтожаются при закрытии; обычный старт не поднимает extension host, локальное ядро или Git-процессы.
- Летопись выполняет только ограниченные read-only Git-команды. Изменение индекса, commit, revert и синхронизация остаются в нативном рабочем дереве и требуют явного действия пользователя.
- Консольные каналы используют нативный PTY/xterm Point. Дополнительные каналы «Сборка» и «Тесты» не запускаются заранее.

## Производительность

- По умолчанию Point использует программный compositor. Исторический контрольный
  Windows-замер показал снижение private memory примерно с 947 до 760–800 МиБ и
  задержки двух первых кадров примерно со 164 до 60 мс; перед новым релизом эти
  значения нужно измерять заново, а не считать гарантией для другой машины.
- Аппаратный GPU можно вернуть переменной `POINT_ENABLE_HARDWARE_ACCELERATION=1` для машин, где драйвер стабилен и приоритетом является максимальная скорость прокрутки.
- История показывает не более 100 последних квестов, активный квест — не более 240 последних событий; полные записи остаются в локальном хранилище.
- Опрос активного квеста сериализован и выполняется не чаще раза в 1,5 секунды: медленный HTTP-ответ не создаёт параллельные запросы, после финального состояния таймер уничтожается.
- Неизменившееся состояние не пересылается и не перерисовывает webview; скрытые Гильдия и ростер не получают фоновые обновления и освобождают renderer-контекст.
- Crash reporter Point отключён: обычный старт использует шесть процессов вместо семи. Локальное ядро, extension host, Git, npm и дополнительные консольные каналы остаются ленивыми.
- Watcher и поиск по умолчанию пропускают генерируемые каталоги `node_modules`, `.cache`, `build`, `dist`, `out`, `target` и `.venv`; настройки можно переопределить для конкретного мира.
