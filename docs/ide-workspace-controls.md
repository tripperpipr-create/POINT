# Окна и клавиатура Point

## Чертог открывается первым

Запуск без аргументов поднимает одно окно — Чертог, домашний экран Point. Прошлая
сессия при этом не восстанавливается: предыдущий мир стоит первым в галерее и
открывается одним нажатием. Любая явная цель ведёт прямо в редактор: `Point.exe
<путь>`, «Открыть с помощью Point», `--folder-uri`, `--file-uri`, ссылка
`point://`. Повторный запуск (клик по значку в панели задач) не открывает пустое
окно, а поднимает уже живой Чертог.

Без выбранного мира Чертог показывает **галерею миров**: список проектов с
ветками и состоянием ядра, поиск, закрепление, «Открыть папку», «Клонировать из
Git…» и «Забыть». Ядро этому экрану не нужно — он работает и в безопасном режиме.
Та же галерея доступна с открытым проектом: `Ctrl+Alt+P` или нажатие на имя мира
в шапке Чертога.

Выбор мира в галерее переключает проект **на месте**, без перезагрузки окна:
рабочая область окна сессий — файл, поэтому подмена папки правит только её JSON.
Ядро прошлого мира при этом не гасится, а отпускается, и возврат к нему стоит
одной проверки здоровья. Бесхозных тёплых ядер держится не больше двух; ядра,
арендованные открытыми окнами IDE, под этот потолок не попадают и не убираются
никогда. Бюджет переключения — `desktop.projectSwitchWarmMs` и
`desktop.projectSwitchColdMs` в `distribution/performance-slo.json`; замер —
`node scripts/measure-point-project-switch.mjs <cdp> <проектA> <проектB>`.

«Открыть в редакторе» (значок ⧉ в карточке мира) поднимает окно IDE на выбранном
проекте. Окно на том же проекте получает фокус, другой проект открывается новым
окном. Окно Чертога кандидатом на переиспользование не становится: его рабочая
область — всегда `agent-sessions.code-workspace`, чем бы ни была подставленная
папка. Закрытие последнего окна IDE Чертог переживает; закрытие самого Чертога
убирает бесхозные тёплые ядра.

## Верхняя панель

Верхняя панель объединяет проект и Git слева, поиск в центре, конфигурацию
запуска и управление окнами справа. Кнопка раскладки открывает собственное меню
«Рабочее пространство». Здесь можно открыть инструменты, переключить левую,
правую и нижнюю панели, разделить редактор справа или снизу, перенести файл в
отдельное окно и снова объединить группы редакторов.

`Ctrl+Shift+F12` скрывает окна инструментов. Повторное нажатие восстанавливает
их прежнюю видимость, сохраняя группы редакторов. Если все панели уже закрыты,
сочетание возвращает панель проекта. Снимок раскладки действует до восстановления
в текущем сеансе IDE.

Кнопка клавиатуры открывает справочник команд с поиском по названию и сочетанию.
Сочетания берутся из текущих настроек пользователя. Внизу есть переход к их
редактированию. На узком окне справочник доступен через «Вид → Горячие клавиши…»
или палитру действий.

Поиск открывается двойным Shift или `Ctrl+N`; текстовый поиск — `Ctrl+Shift+F`.
Стрелки выбирают результат, Enter открывает файл, Shift+Enter открывает его в
соседней группе, Tab переключает раздел, Escape закрывает окно и возвращает фокус.

Проверка новых команд: `npm run test:tool-windows` в `vscode-extension`.
Исходники оболочки распространяются через `distribution/apply-overlay.mjs`;
изменения требуют пересборки Code-OSS и не обновляют установленную IDE автоматически.
