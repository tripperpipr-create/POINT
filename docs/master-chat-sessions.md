# Разговоры с Мастером

Кнопка «Новый чат» создаёт отдельную беседу. Её название автоматически берётся из первого сообщения. «История» позволяет найти беседу по названию, открыть её и переименовать. Переключение сохраняет набранный черновик текущего чата.

Формы ответа: «Авто», «Кратко», «Подробно», «План», «Сначала вопросы». Выбор хранится у беседы и передаётся модели как указание о форме следующего ответа: «Кратко» — несколько предложений, «Подробно» — разбор с примерами и ссылками `path:line`, «План» — пронумерованные шаги. При отсутствии существенных данных мастер должен сначала уточнить их. На вопрос можно ответить прямо в карточке: следующая реплика содержит вопрос и введённый ответ.

## Как устроен ход

Мастер отвечает обычным markdown-текстом, а структуру оформляет вызовами инструментов разговора (`internal/orchestrator/master_actions.go`):

- `propose_brief` — задание на работу. Сервер проверяет его сразу; замечания возвращаются модели результатом вызова, и она присылает исправленное задание в том же ходе. После трёх отвергнутых заданий ход закрывается ответом без карточки с пометкой о причине.
- `ask_clarifications` — до двух уточнений, которые показываются карточкой с вариантами.
- `suggest_memory` — до трёх записей памяти; они попадают в память только после согласия человека.

Кроме них Мастеру доступны только читающие инструменты: файлы, индекс кода, git и чтение запусков, наборов правок и квестов. Правок, команд и сети у него нет; быстрые правки делает быстрый агент, крупные — наряд.

Исследование ограничено восемью кругами по восемь обращений. На пределе ход не падает: модель получает только инструменты разговора и отвечает по собранному, а в «Ходе мысли» видна пометка «ответ по собранному».

## Контекст

Модель получает системную часть, правила проекта (`AGENTS.md` и `CLAUDE.md` из корня, до 16 КБ, как недоверенные данные), снимок проекта, последние 24 реплики дословно и резюме более ранних. Резюме длинной беседы пересчитывается фоном после хода, не чаще раза в четыре хода. Окно берётся из справочника моделей и настроек подключения; если модель неизвестна — 128K. Если запрос не помещается, сначала ужимаются результаты инструментов прошлых кругов, затем выпадают ранние реплики, последними ужимаются результаты текущего круга; лента показывает «контекст сжат». Выбранное задание и текущая реплика с вложениями не урезаются никогда. Если не помещаются даже они, ход отвечает уже сказанным с пометкой в «Ходе мысли», а если сказать было нечего — честно отказывает.

«Память» — редактируемые заметки, общие для чатов проекта. Они передаются модели как пользовательские предпочтения и факты. Мастер может предложить запись сам; предложение ждёт решения человека. Чтобы удалить память, очистите поле и сохраните. Заметки не меняют разрешения инструментов.

Беседы, выбор формы ответа и память хранятся в SQLite ядра. Прежняя переписка доступна как «Первый разговор». Истории бесед разделены; сведения о проекте и задачах остаются общим контекстом. Интерфейс показывает последние 60 реплик.

Любые предложения задач, агентов и отрядов по-прежнему требуют подтверждения пользователя.

Проверки: `go test ./internal/orchestrator ./internal/app -run Master`, `go test ./internal/httpapi`, `node scripts/smoke-master-thread-incremental.js`. Для браузерной проверки: `node scripts/render-hub-surface.js master sessions --out=build/master-sessions.html`, затем `node scripts/smoke-master-session-controls.cjs` (Edge и Playwright из локальной сборки Code-OSS).
