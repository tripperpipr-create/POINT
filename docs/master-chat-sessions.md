# Разговоры с Мастером

Кнопка «Новый чат» создаёт отдельную беседу. Её название автоматически берётся из первого сообщения. «История» позволяет найти беседу по названию, открыть её и переименовать. Переключение сохраняет набранный черновик текущего чата.

Формы ответа: «Авто», «Кратко», «Подробно», «План», «Сначала вопросы». Выбор сохраняется для проекта и передаётся модели как инструкция о форме следующего ответа. При отсутствии существенных данных мастер должен сначала уточнить их. На вопрос можно ответить прямо в карточке: следующая реплика содержит вопрос и введённый ответ.

«Память» — редактируемые заметки, общие для чатов проекта. Они передаются модели как пользовательские предпочтения и факты. Автоматического извлечения сведений из переписки нет. Чтобы удалить память, очистите поле и сохраните. Заметки не меняют разрешения инструментов.

Беседы, выбор формы ответа и память хранятся в SQLite ядра. Прежняя переписка доступна как «Первый разговор». Истории бесед разделены; сведения о проекте и задачах остаются общим контекстом. Интерфейс показывает последние 60 реплик; модель получает ограниченный контекст последних ходов с резюме более ранних реплик из выбранного окна истории.

Любые предложения задач, агентов и отрядов по-прежнему требуют подтверждения пользователя.

Проверки: `go test ./internal/app -run Master`, `go test ./internal/orchestrator ./internal/httpapi`, `node scripts/smoke-master-thread-incremental.js`. Для браузерной проверки: `node scripts/render-hub-surface.js master sessions --out=build/master-sessions.html`, затем `node scripts/smoke-master-session-controls.cjs` (Edge и Playwright из локальной сборки Code-OSS).
