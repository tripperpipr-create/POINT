# ADMIN_FOR_LK: bind / volume — 1 октября 2026

Пять чистых командных пакетов на режим прошли без ошибок, с совпадающими исходниками и digest образа. Медиана пакета с файловым аудитом: **bind 598.593 с**, **volume 33.019 с** — сокращение 94.5%. С созданием отдельного окружения: 614.920 с против 80.912 с (86.8%). Это измерение команд, а не полного квеста/LLM.

[Исходный JSON](quest-dependencies-bind-volume-2026-10-01.json) содержит все 20 измерений (10 пакетов и 10 `true`), setup отдельно и p95. Локальный журнал: `build/quest-dependency-benchmark.log`.

## Протокол

Windows, Docker Desktop 27.2.0; Linux-образ `sha256:cdbf49d1d93902496539b3054c3f02b565f8690972229c0fd221f9e17cb77add`; 2 CPU, память 2 GiB, pids 256. Переносимость `portable-v2`. Исходник — сохранённый результат последнего квеста; digest каждого измерения `sha256:6d803bad41e3f392539776acd4b3e01bf45c50669a9b11e8c16268e1250a2c5b`. Копии до/после проверок совпали; `npm ci` не меняет переносимое дерево. Сетевые hosts взяты из утверждённого наряда, одинаковы для обоих режимов.

Пакет выполняется одним `run_command`: `npm ci --include=dev --no-audit --no-fund`, оригинальный `npm run typecheck`, три оригинальных Jest-набора с `--runInBand`, оригинальный ESLint по пяти файлам. Установленные зависимости каждый раз создаются в новом workspace; повторно используются только download-кеши. Длительность включает файловый аудит команды и запись audit-журнала; setup/copy/init показаны отдельно. Финализация/очистка, LLM, события приложения и полный Flow не входят в пакет.

Порядок: пять bind, затем пять volume, один scope кеша. Первый bind стартует с нового download-кеша, остальные — с накопленным кешем; volume использует тот же уже заполненный кеш. Поэтому это не сравнение cold/cold. Исключение первого bind даёт близкую медиану тёплого bind: 598.897 с. Часть ранних bind-прогонов совпала с другими локальными проверками/восстановлением; порядок не рандомизирован, загрузка Windows не фиксировалась. Нельзя переносить процент на любой компьютер или на модельный этап.

## Приёмка ускорения

На командном контуре этого проекта совпали все проверки и переносимое дерево. Volume пригоден для отдельного сравнительного квеста. Глобальный default bind не изменён. Автоматический rollout остаётся закрыт до трёх полных Qwen3.8-27B квестов на режим с неизменными критериями и evidence. Цель — медиана полного сопоставимого квеста ниже минимум на 30%, ориентир до 24 минут — пока не доказана.

Opt-in полный протокол и ограничения указаны в [отчёте реализации](../implementation-quest-dependencies.md). Ключ провайдера должен поступить через локальную переменную окружения; в JSON/документах ключи не сохраняются.
