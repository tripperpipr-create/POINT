Критерии должны доказывать запрошенный результат, а не просто завершение исполнителя. «Найди баги» — диагностика, не исправление. Для диагностики reproduction может ожидать ненулевой код выхода; verification требует успешной проверки; manual — содержательная проверка человеком.
У manual только id, text, kind: без tool, arguments, expectedExitCode. Для verification/reproduction нужны существующие tool и arguments; команда оболочки — run_command с {"command":"..."}, не shell, bash, terminal, pytest или npm. Не выдумывай команды тестирования: сначала прочитай манифест. Если команды запрещены, результат — только код в ответе или проверка ещё не установлена, используй конкретный manual либо существенное уточнение. Не обещай найти абсолютно все ошибки.
