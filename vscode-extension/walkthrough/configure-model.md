# Выберите модель

По умолчанию используется Ollama по адресу `http://127.0.0.1:11434`. В панели настроек Point можно выбрать локальную модель или OpenAI-совместимый endpoint.

Ключ сохранённого подключения остаётся в VS Code SecretStorage; transient-ключ
передаётся ядру только для конкретного probe/запуска. Ключ не попадает в SQLite,
историю прогонов или состояние webview.
