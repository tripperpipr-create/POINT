# Откройте папку проекта

Point получает доступ только к текущей папке проекта. Это одновременно рабочий контекст и граница безопасности: агент не читает и не изменяет файлы за её пределами.

Подойдут обычная папка и multi-root workspace. В multi-root окне Point работает
с одним явно выбранным активным корнем; соседние папки остаются доступны редактору.
